
# Job Application Management API

A RESTful API built with **Spring Boot** for managing job offers, candidate applications, and recruitment processes.

## Overview

Job Application Management API is a backend application designed to simplify the recruitment process by connecting recruiters and candidates through a centralized platform.

The application provides secure authentication, job offer management, application tracking, notifications, and candidate document management.

## Technologies Used

- **Java 17**
- **Spring Boot**
- **Spring Security**
- **Spring Data JPA / Hibernate**
- **MySQL 8**
- **JWT Authentication**
- **Maven**
- **Docker & Docker Compose**
- **Swagger / OpenAPI**
- **JavaMailSender**

## Features

### Authentication and Authorization

- User registration and login.
- JWT-based authentication.
- Role-based access control (ADMIN, RECRUITER, CANDIDATE).
- Account activation through email verification.

### Job Offer Management

- Create, update, retrieve, and manage job offers.
- Associate job offers with recruiters.

### Application Management

- Candidates can apply for job offers.
- Candidates can view their applications.
- Application status management (PENDING, ACCEPTED, REJECTED).

### Notification System

- In-app notifications.
- Email notifications.
- Application status update notifications.

### Candidate Document Management

- Upload a main CV.
- Upload multiple supporting documents.
- Download and delete uploaded documents.
